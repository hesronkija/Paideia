# Paideia

**Bilingual visual mathematics for Tanzanian secondary students — starting with Form 1.**

Paideia (from the Greek for "education") is an offline-first web app that teaches
mathematics through short, animated, interactive lessons. Every lesson is written
in both **Swahili and English**: explanations in Swahili, exam vocabulary in
English (NECTA exams are English-medium). Examples use everyday Tanzanian life —
splitting TSh 10,000 three ways, sharing chapati and maandazi.

It is built for the reality of its students: low-end Android phones, small
screens, and expensive mobile data. The whole app is ~250 KB, installs to the
home screen, and works **fully offline** after the first load.

Built for one student first — the author's younger sister, starting Form 1 in
January 2027 — then for her friends, then for anyone.

## Stack

- **Vite + React** (plain JavaScript, no TypeScript) — tiny, fast, familiar
- **vite-plugin-pwa** — installable PWA; the service worker precaches every
  asset so lessons work with no network
- **GSAP** — SVG entrance animations for the step-by-step scenes
- **Hand-written CSS** — mobile-first, no frameworks, no Tailwind
- **No backend, no accounts** — progress (completed lessons, best quiz scores)
  lives in the phone's `localStorage`

## Run it

```bash
npm install   # install dependencies
npm run dev   # local dev server with hot reload
npm run build # production build into dist/ (also tests the service worker)
npm run preview # serve the production build locally
```

Regenerate the app icons (white π on green, drawn with zero dependencies):

```bash
npm run icons
```

## How to author a new lesson

A lesson is a **plain JavaScript object**. The engine (`LessonView`) renders it;
you never touch the engine to add content. Copy `src/data/pilotLesson.js` and
fill in your topic. Full schema:

```js
export const myLesson = {
  id: 'ratios-sharing-fairly',   // unique slug; also the progress-storage key
  order: 10,                     // position in the MVP sequence
  syllabusRef: '1.2a',           // TIE 2023 syllabus item (see references/)

  title:    { en: 'Ratios: sharing fairly', sw: 'Uwiano: kugawana kwa haki' },
  subtitle: { en: '…', sw: '…' },// one-line description under the title

  objectives: [                  // "by the end you can…" — shown as a checklist
    { en: '…', sw: '…' },
  ],

  intro: [                       // 1–3 short paragraphs before the scenes
    { en: '…', sw: '…' },
  ],

  scenes: [                      // animated SVG scenes, shown in order
    {
      id: 'sharing-bar',
      title: { en: '…', sw: '…' },
      component: 'SharingBar',   // key in src/components/scenes/index.jsx
      steps: [                   // ONE caption per animation step
        { en: '…', sw: '…' },    // step 0 shows first…
        { en: '…', sw: '…' },    // …step 1 adds more…
      ],
    },
  ],

  workedExamples: [              // story → revealable solution steps
    {
      id: 'ex-1',
      title:   { en: '…', sw: '…' },
      context: { en: '…', sw: '…' },  // the everyday situation (TSh, daladala…)
      steps: [ { en: '…', sw: '…' } ],// revealed one at a time by the student
    },
  ],

  quiz: [
    {
      id: 'q1',
      type: 'mcq',               // or 'truefalse'
      question: { en: '…', sw: '…' },
      choices: [                 // mcq only
        { en: '…', sw: '…' },
      ],
      answer: 2,                 // mcq: index into choices | truefalse: boolean
      explanation: { en: '…', sw: '…' }, // shown instantly after answering
    },
  ],
}
```

**Rules for content:**

1. **Every user-facing string is `{ en, sw }`.** No bare strings in lesson data.
   The `t()` helper (in `lang.jsx`) picks the active language.
2. **Exam terms stay in English**, even inside Swahili text —
   e.g. `Nambari ya juu (numerator)`. NECTA exams are English-medium, so
   students must recognise the English words.
3. **One caption per animation step**, and the scene component must render
   exactly that many steps (see below).
4. **Tanzanian examples, always**: TSh prices, daladala fares, shamba
   measurements, chapati/maandazi sharing.

### How to build a new animated scene

1. Create `src/components/scenes/MyScene.jsx`. It receives `{ step }`
   (0-based) and returns SVG. Use the `<G>` helper:
   ```jsx
   import { G } from './G'
   export default function MyScene({ step }) {
     return (
       <svg viewBox="0 0 360 200">
         <G show={step >= 0} fresh={step === 0}>{/* always visible */}</G>
         <G show={step >= 1} fresh={step === 1}>{/* appears at step 1 */}</G>
       </svg>
     )
   }
   ```
   Elements with `fresh` get the `scene-anim` class, which `ScenePlayer`
   animates in with GSAP. Older elements render without it, so they don't
   re-animate. Keep the `viewBox` roughly 360 wide so scenes scale to phones.
2. Register it in `src/components/scenes/index.jsx`:
   `MyScene,` under a matching key.
3. Reference that key as `component: 'MyScene'` in the lesson data, with one
   `steps[]` caption per visual step.

The player gives you transport controls (previous / play / pause / next /
replay), step dots, and captions for free.

### Registering the lesson

In `src/data/lessons.js`: import your lesson file, flip its entry from
`status: 'soon'` to `status: 'ready'`, and attach `lesson: myLesson`.
It appears on the home screen immediately.

## Roadmap

The 12-lesson MVP covers Form 1 Term 1 of the 2023 TIE syllabus
(full topic map in `references/syllabus-form1-math.md`):

1. What is mathematics? *(1.1a)*
2. Rational, irrational and real numbers *(1.1b)*
3. **Repeating decimals ↔ fractions — the pilot lesson** *(1.1c)* ✅
4. Rational numbers on the number line *(1.1d)*
5. Inequalities and absolute value *(1.1e)*
6. Rounding off *(2.1a–b)*
7. Significant figures *(2.1a–c)*
8. Estimation *(2.1b–d)*
9. Approximations in measurement *(2.1d)*
10. Ratios: sharing fairly *(1.2a)*
11. Proportions in daily life *(1.2b)*
12. Term review: mixed FTNA-style problems

After the MVP: animated NECTA/FTNA past-paper walkthroughs, then Form 1
Terms 2–3.
